# WorldNovel (VNH Fix) for Tsundoku / LNReader JS plugins

Plugin expérimental pour la version actuelle de https://world-novel.fr/ (Victorian Novel House x World Novel).

## Installation dans Tsundoku

Type : **JS Plugin**

URL du dépôt :

`https://raw.githubusercontent.com/Shyun86/Plugin/main/plugins.min.json`

Installe ensuite **WorldNovel (VNH Fix)** depuis les sources Novel.

## Objectif
- Rechercher/ouvrir des œuvres via les routes `/oeuvres/...`
- Lire les métadonnées publiques
- Extraire la liste des chapitres
- Lire le contenu public des chapitres
- Priorité de validation : **Shadow Slave**

## État
Version expérimentale 0.1.0. Le site peut refuser les requêtes externes automatisées alors que sa WebView Android fonctionne ; la validation live doit donc être faite dans Tsundoku.
